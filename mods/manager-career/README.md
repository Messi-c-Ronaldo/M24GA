# 감독 커리어 (manager-career) 0.6.0

내 감독의 **선수 시절 경력**을 게임 안 창에서 자세히 적는 모드예요. FM24의 감독 만들기 화면에는 "과거 선수 경력" 7단계(조기 축구회 ~ 국제 글로벌 수준)만 있는데, 이 모드로 뛴 구단·기간·출전·골·A매치·포지션·좋아하는 구단까지 적을 수 있어요.

## 하는 일

- **게임 안 창:** 세이브를 불러왔을 때 이 세이브에 적은 경력이 없으면 창이 한 번 저절로 열려요. 다시 열려면 앱 설정의 "경력 창 열기" 숫자를 바꿔요.
- **단계 반영:** 창에서 고른 "과거 선수 경력" 단계를 감독에게 써요. 게임은 이 값을 **구단 면접 질문**을 계산할 때 써요. 명성은 바꾸지 않아요 (게임이 감독을 만들 때 이미 계산했어요).
- **맞춰 보기:** 적은 경력(클럽 출전, A매치)으로 추천한 단계와 고른 단계가 두 단계 이상 다르면 확인 창이 떠요 ("추천 단계로" / "고른 대로").
- **보관:** 적은 경력은 세이브마다 보관해요 (이력 20개까지). 0.7.0부터 **게임을 저장할 때 확정**되고, 저장하지 않고 세이브를 다시 불러오면 마지막 저장 때 경력으로 돌아가요 (세이브별 모드 데이터, `%USERPROFILE%\m24ga_data\savedata\<세이브 id>\manager-career\`). 예전 `career.json`은 처음 한 번 가져와요.
- **다시 반영:** 단계를 바꾼 뒤 게임을 저장하지 않고 껐다면, 다음에 불러올 때 보관된 단계를 다시 써요.

## 권한

| 기능 | 왜 |
|---|---|
| `write.relation` | 감독의 좋아하는/싫어하는 구단·사람을 넣고 빼요 (기록·되돌리기) |
| `write.field` | 감독의 과거 선수 경력 칸을 써요. 모든 쓰기는 기록되고 앱(또는 `cli.py undo manager-career`)에서 되돌릴 수 있어요 |
| `pc.python` | 경력 질문·보관을 PC 쪽에서 처리해요 |
| `save.data` | 경력을 세이브와 함께 확정·되돌려요 (코어 0.44.0) |
| `ui.panel`, `read.*`, `event.saveLoaded` | 게임 안 창, 감독·세이브 읽기 (허용 필요 없음) |

## 설정

| 설정 | 기본 | 뜻 |
|---|---|---|
| 경력 창 열기 | 0 | 숫자를 바꿀 때마다 창을 열어요 |
| 새 세이브에서 자동으로 열기 | 켬 | 적은 경력이 없는 세이브를 불러오면 한 번 열어요 |
| 고른 단계를 게임에 반영 | 켬 | 끄면 경력만 보관하고 게임 값은 안 바꿔요 |
| 좋아하는/싫어하는 구단·사람을 게임에 반영 | 켬 | 적은 구단·사람을 감독의 좋아하는/싫어하는 구단·사람으로 넣어요. 끄면 보관만 해요 |

## 알아 둘 것

- 코어 0.25.0 이상이 필요해요. 게임 안 창은 처음 한 번 게임을 다시 켜야 쓸 수 있어요 (로더가 패널 칸 파일을 만든 뒤).
- **0.2.0:** 창에 게임이 알고 있는 좋아하는/싫어하는 구단(감독 만들 때 고른 것)을 보여 주고, 적은 값이 없으면 그 구단으로 채워요. 저장할 때 함께 보관해요.
- **0.3.0:** 적은 좋아하는/싫어하는 구단을 **게임에 넣어요** (감독의 관계 목록, 게임의 관계 더하기 함수를 써요). 구단은 정식 이름이나 짧은 이름으로 찾아요 (예: "토트넘", "FC 서울"). 못 찾으면 알려 줘요. 감독 만들 때 고른 구단은 건드리지 않고, 모드가 넣은 것만 기억해서 다음에 다른 구단을 적으면 이전 것을 빼요. 세이브를 막 불러와 구단 표가 아직 없으면 준비되는 대로 넣어요.
- 구단 쓰기도 기록되고 앱(또는 `cli.py undo manager-career`)에서 되돌릴 수 있어요. 단계와 마찬가지로, 되돌린 뒤 게임을 저장하지 않고 다시 불러오면 보관된 구단이 다시 들어가요. 바꾸려면 창에서 지우고 저장하세요.
- **0.4.0:** "옛 동료·은사(좋아하는 사람)"와 "사이가 나쁜 사람(싫어하는 사람)" 칸이 생겼어요. 게임에 나오는 이름 그대로 적으면(예: "손흥민") 선수·스태프 중에서 찾아 감독의 좋아하는/싫어하는 사람으로 넣어요. 사람 이름 색인은 처음 한 번 30초쯤 걸려서, 그동안은 "잠시 뒤 반영"이라고 하고 준비되면 저절로 넣어요. 창 높이 때문에 "뛴 구단과 기간 3" 칸은 뺐어요.
- **0.5.0 (코어 0.28.0):** 같은 이름의 사람이 여럿이면 저장한 뒤 "같은 이름이 여럿이에요" 창이 떠요. 이름 · 나이 · 소속 구단 (선수/스태프)를 보고 골라요 (최대 8명). 고른 사람은 기억해서 이름을 바꾸지 않는 한 다시 묻지 않아요. "나중에"로 닫으면 다음에 저장할 때 다시 물어요. 고르기 전에는 예전에 넣은 사람을 그대로 둬요.
- **0.6.0 (코어 0.29.0):** 좋아하는/싫어하는 구단·사람 칸이 **게임 검색칸**이 됐어요. 이름을 치는 대로 게임이 후보를 띄워요 (사람은 포지션·직업과 소속 구단, 구단은 리그 순위가 같이 보여요). 고르면 칸 이름 옆에 "(지금: 파울리뉴 · 42세 · 레알 마드리드 CF)"처럼 보이고, 저장하면 고른 그 사람·구단이 들어가요. 고르지 않고 치기만 하면 예전처럼 이름으로 찾아요 (같은 이름이 여럿이면 고르는 창). 칸을 비우려면 "위 구단·사람 칸 모두 비우기"를 켜고 저장하세요 (모드가 넣은 것은 게임에서도 빠져요).
- 적은 뛴 구단(경력)은 아직 보관만 해요.
- 앱에서 되돌리기를 해도 보관된 경력은 그대로라서, 게임을 저장하지 않고 다시 불러오면 보관된 단계가 다시 반영돼요. 단계를 바꾸려면 창에서 바꿔 저장하세요.
