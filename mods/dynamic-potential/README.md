# DynamicPA (포텐 유동 변화, `dynamic-potential`)

선수의 한 시즌 활약에 따라 **잠재력(PA)이 오르내리는** M24GA 모드예요. 평가일(기본 7월 1일)이 지나면 지난 시즌 리그 기록으로 한 번 평가하고, 결과를 미리 보여 준 뒤(또는 바로) 적용해요. 모델은 FM24 Dynamic PA 0.9.5(GPL-3.0)를 그대로 옮겼어요. 출처는 `NOTICE.md`.

## 쓰는 법
1. M24GA 앱에서 이 모드를 켜고 권한(PC 코드 실행, 게임 값 쓰기)을 허용해요.
2. 평소처럼 게임을 해요. 평가일 뒤 30일 안에 모드가 알아서 평가해요 (처음엔 세이브 파일을 읽느라 몇 분 걸려요).
3. 앱의 **모드창** 탭에서 결과를 봐요: "이번 평가 소식"(내 팀 변화, 급성장), 바뀐 선수 표(왜 바뀌었는지 한국어 설명 포함), 필터·검색.
4. 마음에 들면 **바뀐 선수 모두 적용** (두 번 눌러 확인). 반영 방식을 "평가일에 자동 적용"으로 바꾸면 바로 적용돼요.
5. **되돌리기:** 앱의 정보 탭에서 이 모드가 쓴 값을 되돌려요. 적용한 뒤 게임을 **저장**해야 세이브에 남아요. 평가 전에 저장해 두는 걸 권해요.

시험 삼아 보려면 모드창의 **지금 기록으로 미리보기(시험)**: 오늘 날짜로 평가하고, 다음 해에 쓰는 기록에는 안 남겨요.

## 설정
| 설정 | 기본 | 뜻 |
|---|---|---|
| 반영 방식 | 미리보기 후 직접 적용 | 자동이면 평가일에 바로 적용 |
| 평가일 (월·일) | 7월 1일 | 이 날짜 뒤 30일 안에 평가 |
| 드문 사건 (급성장) | 켬 | 뛰어난 어린 선수가 드물게 크게 오름 (같은 세이브·날짜·선수면 결과 같음) |
| 과거 시즌을 세이브 파일에서 읽기 | 켬 | 첫 해부터 지난 2시즌 성적 반영. 같은 세이브 ID의 최근 `.fm`을 읽기만 해요 |
| 장기 부상 반영 | 켬 | 평가 기간 120일 이상 다친 선수는 8~20% 확률로 PA 1~3 하락 (원래 모델에 없는 규칙) |
| 대륙컵·국가대표 반영 비율 | 0% | 0%면 원래 모델(리그 기록만) |
| 반기 점검 | 꺼짐 | 평가일 6개월 뒤 변화량 절반으로 한 번 더 |

## 규칙 요약 (원래 모델)
같은 리그 × 같은 포지션 선수들 사이의 순위(백분위)로 점수를 매겨요. 활약이 좋으면(백분위 70 이상, 출전 조건 충족) 오르고, **부진 판정**(평점 6.7 미만 + 백분위 35 미만 + 팀 평균보다 낮음)일 때만 내려요. 높은 PA는 덜 오르고, PA가 CA보다 훨씬 높으면 덜 오르고, 어린 선수일수록 크게 오르고, 전체 오름 합계는 내림 합계 + 선수 수×0.25를 넘지 못해요. 최종 PA는 CA 이상, 200 이하예요. 자세한 규칙은 개발 기록 `logs/포텐모드/P02`.

## 알아 둘 것
- 평가 대상은 지난 시즌 리그 기록이 있고 비교군(GK 8명, 나머지 12명)이 충분한 선수예요. 작은 리그는 빠질 수 있어요.
- 1~12월 시즌 리그(브라질·J리그·K리그 등)는 직전 완료 시즌(세이브에 보관된 1년 기록)으로 평가해요.
- 평가에는 게임 날짜가 필요해서 **세이브를 연 상태**에서만 돌아요. 평가일에서 30일이 지나 처음 켠 경우 그 해 평가는 건너뛰어요.
- Dynamic PA 프로그램과 **같이 쓰지 마세요** (둘 다 PA를 바꿔요).
