파일은 바꾸지 않아요. 게임 메모리의 엔진 표에 바뀐 값만 써서 재시작 없이 다음 경기부터 반영돼요. 게임이 진행 중일 때는 쓰지 않으니, 멈춘 상태(경기 전)에서 눌러 주세요. 적용 순서: 엔진 팩 → 빠른 조정(배율) → 세부 값(직접 입력).
엔진 팩
내 설정 저장·불러오기 (프리셋)
지금 적용 중인 빠른 조정·세부 값(내가 바꾼 숫자만)을 이름 붙여 저장해요. 파일 하나라서 다른 사람과 주고받을 수 있어요. 게임 원본 값이나 엔진 팩은 들어 있지 않아요. 불러오면 지금 팩은 그대로 두고 조정만 바뀌어요.
빠른 조정 · 기본
고른 팩(없으면 원본) 위에 배율을 곱해요. 1.00 = 그대로. 기본과 고급은 겹쳐서 곱해져요.
빠른 조정 · 고급
세부 값 (엔진 값 하나하나)
원하는 묶음만 펼쳐서 값을 직접 넣어요. 빈칸 = 바꾸지 않음. "기준"은 고른 팩의 값(팩이 없으면 원본)이에요. 세부 값은 빠른 조정보다 나중에 적용돼서 그 값 그대로 들어가요.
