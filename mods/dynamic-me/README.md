# DynamicME (매치엔진 조정)

FM24를 켠 채로 매치엔진을 바꾸는 M24GA 모드예요 (코어 0.33.0 이상).

- **엔진 팩 적용:** 다른 사람이 만든 엔진 팩(`simatch` 폴더)을 골라 **재시작 없이** 넣어요.
  - `simatch.fmf`나 게임 폴더는 바꾸지 않아요. 게임 메모리의 엔진 표에 바뀐 값만 써요.
  - 적용 전에 미리보기에서 팩의 문제를 알려 줘요 (게임이 모르는 키 이름, 0.25초 단위가 아닌 지연, 잘못된 구역 이름 등).
- **직접 조정 (0.8.0: 58개):** 고른 팩(없으면 원본) 위에 배율을 곱해요. 기본 16개 + 고급 42개(모드창에서 "고급 조정 펼치기").
  - 기본: 선수 이동 속도, 가속, 방향 전환, 슛·패스 세기, 헤더 세기, AI 선발 성향 5개(능력·컨디션·폼·명성·유망주), 경기 흐름(모멘텀) 크기, **골 확률(xG) 2개**(필드 슛·직접 프리킥), **AI 전술 성향 3개**(공격 성향·압박·템포)
  - 골 확률 배율은 "골이 될 가능성"에 곱해요 (xG 절편에 ln(배율)을 더함: 2.00 = 가능성 약 2배, 확률이 높은 슛은 덜 늘어요).
  - AI 전술 성향은 10개 전술 스타일 모두의 팀 지시·성향 범위(최소·최대)에 배율을 곱해요 (0~20으로 자름). 게임이 첫 진행일에 전술 스타일을 불러온 뒤 적용돼요.
  - 고급 · 골 확률: 페널티킥. 고급 · AI 전술 성향: 패스 직선성, 공격 폭, 유동성
  - 고급 · 선수 움직임: 걷기·조깅 / 달리기·전력질주 / 가속 / 감속 / 골키퍼 다이빙 / 최대 회전 / 방향 전환
  - 고급 · 공: 짧은 패스 / 중간 패스·크로스 / 강한 슛·롱볼 세기
  - 고급 · 경합·반칙 (최소 지연, 0.25초 단위): 태클 시도 간격, 태클 당한 뒤 회복, 몸싸움, 거친 행동·걸기, 헤더, 골키퍼 동작, 부상·넘어짐, 기타
  - 고급 · AI 선발: 포지션 능력, 전술 익숙함, 사기·불만, 출전 약속, 휴식 약속, 선수 성향(PPM), 컵 키퍼·2군, 주장·A매치·발 방향
  - 고급 · 경기 평점: 득점, 도움·찬스, 슈팅, 패스·드리블, 수비, 골키퍼, 실수·카드, 팀 득실, 예상보다 잘하고 못한 결과
  - 고급 · 경기 흐름: 골, 골이 아닌 슛, 패스·터치
- **세부 값 (0.3.0, 0.4.0):** 엔진 값 하나하나를 한국어 이름·원본 값·팩 값과 함께 보고 직접 넣어요. 묶음 23개, 950칸 (전술 스타일 10묶음 440칸, xG 77칸 포함):
  - 선수 물리: 이동 속도 13, 킥·헤더·골키퍼 다이빙 11, 가속·감속 6, 회전·방향 전환 7, 경합·반칙·골키퍼 최소 지연 39
  - AI 선발 가중치: 선발 방식 4개(1군 ~ 전면 로테이션) × 요인 39
  - 경기 흐름(모멘텀) 48칸 (사건 × 구역 × 좌우)
  - 경기 평점: 계수 52개 배율(모든 역할에 곱함), 시작 평점, 예상 결과 배율 11쌍
  - 적용 순서: 엔진 팩 → 빠른 조정(배율) → 세부 값(그대로 들어감)
- **전술 스타일 (0.4.0):** AI 감독이 스타일(점유율 중시, 게겐프레스 … 버스 세우기 10개)별로 팀 지시·성향을 고르는 범위(`tactics/styles.xml`)도 넣어요.
  - 엔진 팩의 `styles.xml`을 재시작 없이 넣어요. 팩이 새로 더한 성향 항목(창의적 자유, 대인 마크, 수비 라인 유지, 크로스 막기 등)도 들어가요.
  - 세부 값에 스타일마다 묶음이 있어요 (팀 지시 8 + 성향 14 = 최소·최대 44칸). '-'는 그 스타일에 없는 항목이고, 값을 정하면 더해요.
  - 게임은 세이브를 불러온 뒤 **첫 진행일에** 전술 스타일을 불러와요. 그 전에 적용하면 "아직 불러오지 않았어요"라고 알리고, 불러오는 순간 모드가 알아서 넣어요.
- **모드창은 파트마다 접고 펼 수 있어요** (엔진 팩, 빠른 조정 기본·고급, 세부 값과 그 안의 묶음). 접힌 묶음에도 바꾼 개수가 보여요.
- **원본으로:** 버튼 하나로 게임 설치 폴더의 원본 값으로 돌아가요.
- 엔진 값은 세이브에 남지 않아요. 설정 "게임을 켤 때 다시 적용"이 켜져 있으면 모드가 게임에 붙을 때 마지막 팩·조정을 다시 넣어요.

- **프리셋 (0.7.0):** 지금 적용 중인 빠른 조정·세부 값(내가 바꾼 숫자만)을 이름 붙여 저장하고 불러와요. 파일 하나(`.json`)라서 다른 사람과 주고받을 수 있고, 게임 원본 값이나 엔진 팩은 들어 있지 않아요. 불러오면 지금 팩은 그대로 두고 조정만 바뀌어요.
- **zip 팩 (0.7.0):** 엔진 팩을 압축(.zip) 그대로 팩 폴더에 넣거나 경로에 넣어도 돼요. 엔진 표 파일(.json·.jsb·.xml)만 모드 데이터 폴더에 풀어 쓰고, 소리 같은 큰 파일과 폴더 밖을 가리키는 항목은 건너뛰어요.
- **세부 값 검색 (0.7.0):** 묶음을 펼치지 않고 이름(예: 프리킥, 속도, 압박)으로 바로 찾아 값을 넣어요.
- **미리보기 대표 값 (0.7.0):** 팩을 고르면 최고 속도 8.94 → 9.9 같은 대표 값을 원본과 나란히 보여 줘요.

## 쓰는 법

1. 앱에서 모드를 켜고 `write.engine`(게임 값 쓰기) 권한을 허용해요.
2. 엔진 팩을 `문서\M24GA\engines\<팩 이름>\` 에 넣어요. 또는 모드창에 경로를 직접 넣어요.
3. 모드창에서 미리보기를 보고 적용해요. 게임 진행을 멈춘 상태(경기 전)에서 눌러요.

- **xG 모델 (0.5.0):** 엔진 팩의 xG 계수·절편(`expected_goals/models`)도 넣어요. 세부 값 "xG 모델" 묶음에서 슛 종류 11개의 절편·계수 77칸을 직접 고쳐요.
- **QME (0.6.0, 재시작 필요):** 빠른 경기(사람이 안 보는 경기)의 선수 기록 표 두 개는 팩마다 표 모양이 달라 메모리에 바로 못 써요. 게임 폴더에 엔진 폴더(`data\simatch`)가 있으면 그 폴더의 두 파일을 팩 내용으로 바꾸고, **게임을 다시 켜면** 적용돼요. 원본으로·팩 빼기를 하면 원본 파일로 돌려놔요. 미리보기는 게임이 모르는 기록 이름도 알려 줘요 (팩이 기록 이름을 바꿨으면 그 항목은 게임이 버려요).

## 지금 못 하는 것 (0.6.0)

- 엔진 폴더(`data\simatch`)가 없는 PC에서는 QME를 넣지 못해요 (폴더 설치 기능은 아직 없어요). QME는 재시작 전까지 적용되지 않아요.
- 해설(`events/`), 공 물리(`.bta`), AI 전술 프리셋(`.tac`·`.stra`)은 아직 다루지 않아요. 팩이 이 파일을 바꿨으면 미리보기에 "못 넣음"으로 알려요 
- 전술 스타일의 선호 역할·경기 특징·좋아하는 능력치(설명용 목록)는 넣지 않아요 (엔진 팩들도 바꾸지 않아요).
- 미리보기는 팩이 **게임이 쓰지 않는 옛 버전 항목**만 바꾼 경우도 알려요 (FM24는 물리 22.6.0.2, 선발 가중치 24 항목을 써요).

## 만든 방법

조사 기록은 M24GA 저장소 밖 로그(`logs/메치엔진조정모드`, E01~E09)에 있어요. 코어 쪽 `api.engine`, 변환·계획은 `pylib/m24engine.py`예요.

## 처음 시작할 때

- 모드에는 엔진 팩이 들어 있지 않아요. 처음에는 **팩 없음 · 조정 없음 · 세부 값 없음 = 게임 원본 엔진**으로 시작해요.
- 팩은 사용자가 직접 구해서 `문서\M24GA\engines\` 에 넣어요. 다른 사람이 만든 엔진 팩은 이 모드로 재배포하지 않아요.
