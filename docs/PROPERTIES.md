# 게임 속성 코드 (확인된 것)

`getVal(obj, '코드')` / `getInt(obj, '코드')`로 읽는 4글자 속성 코드 중 **이 프로젝트에서 게임 화면과 맞춰 본 것**만 적어요 (기능 `read.data`).
`obj`는 데이터 표에서 `lookup`으로 꺼낸 객체예요: 클럽은 `lookup(clubs, idx, CLUB_VT)`, 선수는 `lookup(persons, idx, PERSON_VT)`, 감독·스태프는 `lookup(staff, idx, STAFF_VT)`.

- 게임에는 코드가 훨씬 더 많지만(`properties.fmf`에 800개 넘게), 대부분은 화면 상태에 따라 값이 달라지거나 뜻을 확인하지 못했어요. **여기 없는 코드는 값이 맞는지 직접 확인하고 쓰세요.** 잘못된 코드는 `null`을 돌려줘요 (게임이 튕기지는 않아요).
- 확인 근거는 `logs/AI소셜피드` 18·19·31·33·34·38번 로그예요.
- 값 형식: 정수 `getInt`, 객체·목록·글자 `getVal`. `getVal`은 `{4글자 키: 값}` 객체, 배열, 숫자, 글자 중 하나를 돌려줘요.

## 클럽 (`clubs` 표)

| 코드 | 뜻 | 형식 / 비고 |
|---|---|---|
| `TpoN` | 리그 순위 | 정수 |
| `Tomp` | 이번 시즌 경기 수 | 정수 |
| `Tlgs` / `Tlgc` | 리그 득점 / 실점 | 정수 |
| `Cmxp` | 미디어 예상 순위 | 정수 |
| `Tnts` | 이적 순지출 | 정수 (게임 내부 단위, 원화 환산은 ×1664.7) |
| `Tfrm` | 최근 5경기 | 배열, **[0]이 가장 오래된 것**, 3 승 / 1·2 무 / 0 패 |
| `Topp` | 다음 경기 상대 | `{dref}` (0x18xxxxxx = 클럽 링크 번호) |
| `TMnR` | 지금 팀 감독 (임시 감독 포함) | `{dref}` (0x01xxxxxx = 사람 링크 번호) |
| `Tstg` / `Tsma` / `Tsar` | 팀 최다 득점자 / 도움 1위 / 최고 평점 | `{plys: [{dref}], valu}` |
| `Ctfc` / `Ccba` / `Ccww` / `Cwwb` | 이적 예산 / 잔고 / 주급 총액 / 주급 예산 | 정수 (내부 단위) |
| `ccca` / `ccms` | 구단 분위기 / 감독 지지도 | 정수 |
| `Cvag` | 스쿼드 평균 나이 | 실수 |
| `Ctpr` | 티켓 가격 | 실수 |
| `duni` | 클럽 고유 ID (팬 응원 클럽 `Salo`와 같은 번호) | 정수 |

쓰지 마세요: `Twir`/`Tlir`/`Tgww`(연승·연패·무승, 서로 모순되는 값), `Tsof`(정체 불명).

## 선수·사람 (`persons` 표)

| 코드 | 뜻 | 형식 / 비고 |
|---|---|---|
| `Pnam` | 이름 | `{Pfna: 전체 이름, ...}` |
| `Page` | 나이 | 정수 |
| `PAap` / `PAcg` | 통산 출전 / 골 | 정수 |
| `PCRP` | 명성 | 정수 (0~10000) |
| `Pmor` | 사기 | 정수 (1~20) |
| `Poav` | 시즌 평균 평점 | `{valu, numb(출전)}` |
| `Pgls` | 시즌 골 | `{valu, numb}` |
| `Pfrm` | 최근 폼 | `{Prat 평균, Pgls 골, Pfrm [최근 5경기 평점]}` |
| `Poyc` / `Porc` / `PoxG` | 시즌 경고 / 퇴장 / xG | `{valu, numb}` |
| `Piap` / `Pigl` | 국가대표 출전 / 골 | 정수 |
| `Pgoa` `Pdce` `Pdls` `Pdrs` `Pwbl` `Pwbr` `Pdmc` `Pmce` `Pmls` `Pmrs` `Pamc` `Paml` `Pamr` `Pace` | 포지션 숙련도 (골키퍼, 중앙 수비 … 스트라이커) | 정수 1~20 (`mainPosition`이 가장 높은 것을 고름) |
| `Pcvy` / `Ploy` / `Pamb` / `Pipr` | 논란 성향 / 충성심 / 야망 / 부상 경향 (숨은 값) | 정수 1~20 |
| `duni` | 고유 ID (= 선수 객체 UID, `personUid`) | 정수 |

현재 능력(CA)과 잠재력(PA)은 속성 코드가 아니라 **선수 객체**에서 읽어요: `playerInfo(playerOf(o))` (기능 `read.player`).

## 감독·스태프 (`staff` 표)

| 코드 | 뜻 | 형식 |
|---|---|---|
| `Page` | 나이 | 정수 |
| `Nptk` / `Npmm` / `Npde` | 전술 지식 / 선수 관리 / 결단력 | 정수 1~20 |
| `Ncrr` | 감독 명성 | 정수 |
| `Nppf` / `Npsf` / `Npaf` / `Npdf` | 선호 포메이션 (1순위 / 2순위 추정 / 공격·수비 추정) | 정수 0~65 (포메이션 번호) |
| `Ntem` | 기질 (숨은 값) | 정수 1~20 |
| `Pcvy` / `Ploy` / `Pamb` | 논란 성향 / 충성심 / 야망 (숨은 값) | 정수 1~20 |
