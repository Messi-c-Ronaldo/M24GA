# M24GA 함수 목록 (코어 0.35.0)

> 이 파일은 `core/functions.json`에서 `python -X utf8 tools/m24.py caps`로 만들어요. 직접 고치지 마세요.

게임 함수에 끼어들어요: `api.hook('이름', { before: function (ev) {}, after: function (ev) {} })` (기능 `hook.function`, 사용자 허용 필요). `ev.args`(형식대로 바꾼 인자), `ev.raw(i)`, `ev.caller`, `ev.tid`, `ev.data`(before → after), after에서 `ev.ret`. **끼어들기: modify**인 함수만 `ev.setArg(i, v)`(before) / `ev.setRet(v)`(after)로 바꿀 수 있어요. 콜백은 게임 스레드에서 불리니 짧게 하세요.
코어는 함수마다 하나만 걸고 여러 모드에 나눠 줘요. 모드를 내리면 자동으로 떼요. 서명(`sig`)이 이 빌드와 다르면 걸지 않아요.
새 함수는 `core/functions.json`에 한 줄 더하면 돼요 (찾는 법: CLI `watch-write`로 그 칸에 쓰는 함수, `watch-call`로 인자·호출자 관찰, REA 디컴파일). 인자 뜻을 확인하지 못했으면 `verified: false`, 끼어들기는 `observe`로 두세요.
